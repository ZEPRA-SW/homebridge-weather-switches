Homebridge Weather Switches ZEPRA 0.6.5

Location and switches

Worldwide weather rules for virtual HomeKit switches. Expand each switch, add conditions and reorder using the arrows.

Open-Meteo uses weather models; DWD uses actual station observations. Sensor displays are optional. Switches follow their rules automatically and cannot be controlled manually.

Apply changes using the Homebridge Save button, then restart Homebridge. Keep permanent IDs.

Weather data by Open-Meteo · CC BY 4.0. Rule states are derived from these data. Free API for non-commercial use only, including personal home automation. Coordinates are sent to Open-Meteo.

Data source when DWD is selected: Deutscher Wetterdienst, CC BY 4.0. Station catalogue filtered; observations converted into rule states and optionally estimated lux values.
